## Role Description

The Senior DevSecOps Engineer is a full-time, on-site position based in Kalyan Dombivli. This role is responsible for designing, implementing, and maintaining secure CI/CD pipelines, integrating security controls into every stage of the software development lifecycle. The engineer will manage cloud and on-premise infrastructure, automate deployments, monitor system performance, and ensure compliance with security best practices and standards.

Daily tasks include collaborating with development and operations teams, performing vulnerability assessments, managing incident response, and improving tooling and processes for reliability, scalability, and security. The role also involves mentoring team members, documenting procedures, and contributing to architectural decisions that support eCommerce growth.

## Qualifications

- Strong foundation in Computer Science principles, including data structures, algorithms, and system design.
- Proficiency in Back-End Web Development and Software Development, with experience building and maintaining APIs and microservices.
- Advanced Programming skills in one or more languages commonly used in DevSecOps environments (e.g., Python, Go, Java, or similar).
- Solid understanding of Object-Oriented Programming (OOP) concepts and their application in secure, maintainable codebases.
- Hands-on experience with CI/CD tools (e.g., Jenkins, GitLab CI, GitHub Actions) and infrastructure-as-code frameworks (e.g., Terraform, Ansible).
- Experience implementing security practices across the SDLC, including code scanning, dependency management, and container security.
- Practical knowledge of cloud platforms (e.g., AWS, Azure, GCP) and Linux-based systems administration.
- Ability to collaborate effectively with cross-functional teams, communicate clearly, and document processes and standards.
- Bachelor’s degree in Computer Science, Engineering, or a related field, or equivalent practical experience.
- Experience in eCommerce or high-traffic web applications is an advantage; relevant security certifications (e.g., CISSP, OSCP, CSSLP) are a plus.
