
# DevSecOps Specialist – Application, Infrastructure & AI Security

## 💼 Job Description

We are looking for a skilled **DevSecOps Specialist** with expertise in application and infrastructure security, secure software development practices, and security automation.

The ideal candidate will possess strong scripting capabilities in Python and Linux Shell Scripting, along with hands-on experience integrating security throughout the SDLC and CI/CD pipelines.

This role requires a proactive security mindset and the ability to drive secure engineering practices across cloud-native and AI-enabled environments.

## 🔑 Key Responsibilities

- Design, implement, and enhance DevSecOps practices across software development and deployment pipelines.
- Integrate and manage security testing tools, including SAST, DAST, dependency scanning, and container security solutions.
- Develop and maintain security automation scripts using Python and Linux Shell Scripting.
- Perform application and infrastructure security assessments and drive remediation efforts.
- Collaborate with development, operations, and security teams to embed security controls within the SDLC.
- Implement and manage security controls within Azure DevOps CI/CD pipelines.
- Support the secure adoption of AI/ML solutions through AI security assessments, governance, and risk management practices.
- Develop and maintain security standards, policies, and best practices for cloud, DevOps, and AI-enabled environments.
- Monitor emerging threats and recommend appropriate security controls and mitigations.

## 🛠️ Must-Have Skills

- Extensive experience in DevSecOps, Application Security, or Infrastructure Security.
- Strong proficiency in Python and Linux Shell Scripting.
- Hands-on experience with:
  - Static Application Security Testing (SAST)
  - Dynamic Application Security Testing (DAST)
  - Dependency Scanning
  - Container Security
- Experience integrating security tools into SDLC and CI/CD pipelines.
- Azure DevOps CI/CD pipeline security.
- Application and Infrastructure Security Assessment.
- Security Automation and Vulnerability Remediation.
- Secure Software Development Practices.
- AI/ML Security, Governance, and Risk Management.
